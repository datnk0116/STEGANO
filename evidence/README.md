# Evidence

Store screenshots in the folders used by this repository:

- `terminal/` — direct captures of environment checks, CLI runs, tests, and Streamlit startup. The corresponding logbook and appendix entries link to each capture.
- `visualization/` — screenshots of the Streamlit pages, intermediate diagnostics, and displayed results. A run-log screenshot may also be stored here when it shows the saved `.log` rendered in a browser.

Keep raw text logs and JSON results under `results/`, not here. Capture screenshots directly from the running application or Terminal and keep them unaltered. Label a rendered log view accurately; do not describe it as a terminal capture.
